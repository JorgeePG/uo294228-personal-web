Cómo usar la web

Pulsa Tab para pasar de un enlace o control al siguiente y Mayús + Tab para retroceder. Actívalos con Enter; en los botones también puedes usar Espacio. El primer enlace permite saltar al contenido.

En los carruseles puedes usar los botones, deslizar o pulsar las flechas izquierda y derecha cuando el carrusel tiene el foco. No avanzan automáticamente. En las fotografías ampliadas, usa Cerrar imagen o Escape para volver.

El menú indica tu sección actual. Puedes cambiar entre español e inglés desde la cabecera.

¿Algo no funciona?

Si un audio o vídeo no se reproduce, usa su enlace de descarga. Si un enlace está roto o necesitas el contenido en otro formato, escribe a uo294228@uniovi.es indicando la página y el problema.
